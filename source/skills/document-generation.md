# Dyslexia Document Generation Skill

## Purpose
Generate professional, standards-compliant documents for dyslexia support — including IEPs, 504 plans, progress reports, accommodation letters, screening checklists, evaluation summaries, and intervention documentation.

> **Cognitive Disorder Framing**: All generated documents frame dyslexia as a neurodevelopmental cognitive disorder — a persistent, brain-based difference in phonological and orthographic processing (left temporoparietal cortex, VWFA, inferior frontal gyrus). Documents distinguish between remediation targets (skills expected to improve with structured literacy instruction) and bypass targets (persistent processing differences requiring permanent accommodation as cognitive prosthetics).

## Document Templates

### 1. Individualized Education Program (IEP)

**Required Sections:**

```
INDIVIDUALIZED EDUCATION PROGRAM

Student Information
├── Name, DOB, Grade, School
├── Disability Category: Specific Learning Disability (Dyslexia)
│   (Neurodevelopmental cognitive disorder — brain-based phonological/orthographic processing difference)
├── IEP Date, Annual Review Date
└── IEP Team Members (must include dyslexia-knowledgeable member)

Present Levels of Academic Achievement and Functional Performance (PLAAFP)
├── Current Performance Data
│   ├── Standardized assessment results (with dates)
│   ├── Curriculum-based measurement data
│   ├── Classroom performance observations
│   └── Grade-level comparisons
├── Impact of Disability
│   ├── How dyslexia (as a persistent cognitive processing difference) affects involvement in general education
│   ├── Specific academic areas affected
│   └── Functional impact (self-esteem, participation, independence)
└── Strengths and Interests

Measurable Annual Goals
├── Goal Area: Phonological Awareness / Decoding
│   ├── Baseline: [current performance]
│   ├── Goal: [measurable target with criteria and timeframe]
│   └── Measurement: [tool, frequency, criteria for mastery]
├── Goal Area: Reading Fluency
│   ├── Baseline → Goal → Measurement
├── Goal Area: Reading Comprehension
│   ├── Baseline → Goal → Measurement
├── Goal Area: Spelling / Written Expression
│   └── Baseline → Goal → Measurement
└── [Additional goals as needed]

Special Education Services
├── Service Type (e.g., Specialized Reading Instruction)
├── Methodology (e.g., Wilson Reading System, Barton)
├── Frequency (e.g., 5x/week)
├── Duration per session (e.g., 45 minutes)
├── Location (e.g., resource room, general education with support)
├── Start Date and End Date
└── Provider qualifications

Accommodations and Modifications
├── Classroom Accommodations
│   ├── Extended time (specify: 25%, 50%, or time-and-a-half)
│   ├── Preferential seating
│   ├── Reduced workload (specify how)
│   ├── Note-taking assistance
│   └── Audio recordings permitted
├── Testing Accommodations
│   ├── Extended time
│   ├── Read-aloud / text-to-speech
│   ├── Separate setting
│   ├── Alternative format
│   └── Scribe or speech-to-text
├── Technology Accommodations
│   ├── Text-to-speech software
│   ├── Speech-to-text software
│   ├── Spell-checker / grammar tools
│   └── Audiobooks / digital text
└── Homework Accommodations

Progress Monitoring
├── Tools and measures for each goal
├── Reporting frequency (minimum: with each report card)
├── Data collection methods
└── Decision rules for adjusting instruction

Transition Plan (if applicable, age 16+)
├── Postsecondary goals
├── Transition services
└── Self-advocacy skills development
```

**Goal Writing Guidelines:**
- Use SMART format: Specific, Measurable, Achievable, Relevant, Time-bound
- Include baseline data, target criteria, measurement tool, and timeframe
- Example: "By [date], given a list of 20 grade-level words containing taught syllable patterns, [Student] will decode with 85% accuracy as measured by weekly curriculum-based probes, improving from a current baseline of 45% accuracy."

### 9. ADA Title I Workplace Accommodation Request Letter

```

[Date]

[HR Director / Manager Name]
[Company Name]
[Address]

I am writing to formally request reasonable accommodations under the Americans

affects my ability to process written text at typical reading rates.

Functional Impact on Work:
[Specific, job-related description. For example:]
- I process dense written text at approximately half the rate of a typical reader
- Reading-heavy compliance training materials take me 2-3× longer to complete
- I produce higher-quality work when I can process documents via text-to-speech
- My written communication is more accurate when I can use advanced spelling
  and grammar tools

Requested Accommodations:
I am requesting the following accommodations, which I believe are reasonable
and will enable me to perform the essential functions of my position:

1. **Text-to-speech software** — Installation of [Natural Reader / Read&Write /
   JAWS] on my work computer for processing written communications, reports,
   and training materials

2. **Speech-to-text software** — [Dragon NaturallySpeaking / Windows Speech
   Recognition] for drafting longer written communications

3. **Grammar and spelling support** — Grammarly Business license or equivalent

4. **Advance document access** — When possible, receiving reading-heavy documents
   24 hours in advance so I can process them via my accessibility tools

5. **Written summaries** — Written summaries of complex verbal instructions,
   reducing working-memory load

6. **Extended time for reading-based assessments** — 1.5× extended time on
   performance reviews, compliance certifications, and any timed reading-based
   assessments

7. **Quiet workspace option** — Access to a quiet area for deep-focus reading
   tasks when needed

8. **Meeting recording permission** — Permission to record meetings (with
   attendee consent) so I can review via text-to-speech transcripts

Supporting Documentation:
I have attached clinical documentation from [Evaluator Name, Credentials] dated
[Date] confirming the diagnosis and supporting the accommodations requested.
I am happy to provide additional information that is job-related and consistent
with business necessity.

Interactive Process:
I welcome the opportunity to discuss these requests through the interactive
process required by the ADA. I am open to alternative accommodations that
would be equally effective. Please let me know your availability for a meeting
to discuss these accommodations.

Confidentiality:
I understand that medical information I provide will be kept confidential and
stored separately from my personnel file, as required by the ADA.

Thank you for your attention to this request. I look forward to continuing to
contribute effectively to [Company Name].

Sincerely,

[Employee Name]
[Job Title]
[Contact Information]

cc: [Optional — ADA Coordinator, Disability-Inclusive Business Resource Group]
```

### 11. Cognitive Prosthetics Prescription / Recommendation Letter

```
COGNITIVE PROSTHETICS RECOMMENDATION

Provider: [Licensed clinician name, credentials, license #]
Patient/Client: [Name]    DOB: [Date]    Date: [Date]

Re: Recommended Cognitive Prosthetics for Dyslexia

Diagnosis:
├── DSM-5: 315.00 Specific Learning Disorder With Impairment in Reading
├── ICD-11: 6A03.0 Developmental Learning Disorder
└── Severity: [mild / moderate / severe]

Clinical Basis:
The following recommendations are based on the persistent nature of dyslexia
as a neurodevelopmental cognitive disorder. While structured literacy
instruction can improve decoding accuracy and fluency, the underlying
phonological processing differences persist throughout life. Cognitive
prosthetics are medically appropriate lifelong supports, analogous to
eyeglasses for refractive errors or hearing aids for hearing loss.

Recommended Cognitive Prosthetics Stack:

**Reading Support**
├── Text-to-Speech (TTS)
│   ├── Desktop: [Read&Write / Natural Reader / Voice Dream / Balabolka]
│   ├── Mobile: [Voice Dream Reader / Speechify / Natural Reader Mobile]
│   ├── Browser: [Read Aloud / Read&Write Chrome extension]
│   └── Use case: processing dense text, lengthy documents, complex vocabulary
├── Audiobook Services
│   ├── Learning Ally (human-narrated educational materials)
│   ├── Bookshare (accessible texts, free with qualifying disability)
│   └── Audible (commercial audiobooks for leisure reading)
├── OCR Tools
│   ├── [Kurzweil 3000 / Read&Write / Adobe Acrobat Pro]
│   └── Use case: converting scanned documents and images to accessible text
└── Visual Supports
    ├── Dyslexia-friendly fonts: Lexend, Atkinson Hyperlegible, OpenDyslexic
    ├── Reading rulers / focus overlays
    └── Color overlays for users with Irlen Syndrome comorbidity

**Writing Support**
├── Speech-to-Text (STT)
│   ├── [Dragon NaturallySpeaking / Windows Speech Recognition / Apple Dictation]
│   └── Use case: drafting longer documents, reducing spelling burden
├── Grammar and Spelling Tools
│   ├── [Grammarly / Ginger / Word Spell-Check / LanguageTool]
│   └── Use case: professional written communication
└── Word Prediction
    ├── [Co:Writer / WordQ / built-in predictions]
    └── Use case: reduces spelling effort for frequent writers

**Organization and Memory**
├── Task management: [Todoist / Asana / Microsoft Planner]
├── Mind mapping: [MindNode / MindMeister / XMind]
└── Visual project tracking: [Trello / Notion / Airtable]

Rationale:
These prosthetics are not optional preferences or temporary scaffolds. They
compensate for persistent differences in how the individual's brain processes
written language. The client should have consistent access to these tools
across educational and occupational settings.

Accommodation Settings Where Prosthetics Should Be Available:
☐ Academic (K-12, college, graduate school)
☐ Workplace
☐ Standardized testing
☐ Professional licensure
☐ Healthcare settings (for patient-facing materials)
☐ Legal proceedings (when written documentation is required)

This recommendation letter may be used to support:
├── ADA Title I workplace accommodation requests
├── Higher education disability services requests
├── Testing accommodation requests (GRE, LSAT, MCAT, bar exam, etc.)
├── Insurance reimbursement for assistive technology
└── Vocational rehabilitation services

Provider Signature: _____________________    Date: _______
License #: _____________________    State: _______
```

## Behavior Guidelines

- All generated documents must align with IDEA requirements and IDA standards (US), or the applicable French (Loi 2005-102 / Circulaire 2015-016 / Circulaire 2023-033) or Spanish (LOE/LOMLOE / RDL 1/2013) legal frameworks.
- Use person-first or identity-first language based on user preference (default: "student with dyslexia" / "estudiante con dislexia" / "élève dyslexique").
- Frame dyslexia consistently as a neurodevelopmental cognitive disorder — a brain-based difference in phonological/orthographic processing, not a reflection of intelligence, effort, or character. Carry this framing into FR/ES documents (the cognitive prosthetics sections in PAP / ACNS templates make this explicit).
- All accommodation sections should frame bypass tools (text-to-speech, spell-checkers, audiobooks, dictation) as permanent cognitive prosthetics, not temporary supports to be withdrawn. Apply locale-appropriate tools: US (Read&Write, Voice Dream, Grammarly), FR (Vocale Presse, Antidote, Dragon FR), ES (Vozme, StilusNet, Dragon ES).
- Goals must be genuinely measurable — include specific numbers, tools, and timeframes.
- Never generate a 504 plan when the student profile clearly indicates need for IDEA/IEP services. Flag this to the user.
- Include all legally required sections. Missing sections create compliance risk.
- Accommodate state-specific requirements when the user specifies their state (US), académie/département (FR), or Comunidad Autónoma (ES).
- Use clear, jargon-free language in parent-facing documents.
- Mark all templates clearly as templates requiring professional review — these are starting points, not substitutes for qualified professional judgment.
- Progress monitoring reports should include visual data representation when possible.

**French document guidelines (locale=fr):**
- The PAP template must match the correct school cycle (maternelle / élémentaire / collège / lycée) — there are four distinct versions.
- The médecin de l'Éducation nationale signature is legally required to validate the PAP. Flag if missing.
- A PAP cannot coexist with a PPS. If generating a PAP, note that MDPH recognition is NOT required and should NOT be pursued for the PAP pathway.
- Exam accommodation requests must cite the specific PAP/PPS entries showing that accommodations are already used in class. A request without this linkage is likely to be refused.
- The Défenseur des Droits is the appropriate body to cite for appeal if accommodations are refused.
- For adult/workplace contexts, transition from PAP/PPS framing to RQTH framing; cite Code du travail Art. L1132-1 for anti-discrimination protections.
- Write French documents in French unless the user requests otherwise.

**Spanish document guidelines (locale=es):**
- Verify and use the correct regional terminology for the Comunidad Autónoma before generating ACNS documents (e.g., PTI in Castilla-La Mancha, ACI in some other regions).
- Always include the explicit statement that the student is classified as DEA (not NEE) and that ACNS is the appropriate instrument (not ACS/Dictamen).
- Family agreement signature is required on ACNS documents.
- ACNS must be applied across all subjects where difficulties manifest — not only in language class.
- When generating ACNS for dyscalculia, include spelling/orthographic accommodation wording even if the primary concern is mathematics, as comorbid orthographic difficulty is common.
- For EBAU/EvAU accommodation requests: verify documented ACNS history during Bachillerato, otherwise the request is likely to be refused.
- For adult/workplace contexts, cite RDL 1/2013 and reference the 33% certificado de discapacidad threshold where applicable.
- Write Spanish documents in Castilian Spanish unless the user requests another regional language (Catalan, Basque, Galician).
